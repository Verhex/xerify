# Brand

The Xerify mark is a custom composite. Its ink upper `V` begins the `Verify` reading; an asymmetric
emerald mirrored check meets it at the center. Together they form the `X` in `Xerify`. The primary
line is:

> Verify before you trust.

The descriptor is:

> A model-independent verification layer for AI systems.

## Assets

The owner-approved geometry is the **attached-center asymmetric X**. The upper path is a narrow ink
`V`; the lower path has a short left arm and long right arm so it reads as a mirrored check rather
than a second chevron. `assets/logos/source/xerify-master.svg` is the deterministic vector source,
and `xerify-exploration-grid.svg` records the approved construction. The `erify` wordmark uses
custom SVG outlines and has no font dependency.

Horizontal, icon-only, black, and white SVG variants live under `assets/logos/`. PNG icon exports at
16, 24, 32, 64, 128, 256, 512, and 1024 px are generated by `npm run assets:logo`. Icon SVGs use a
padded square canvas so the same deterministic exporter produces uncropped square PNGs at every
size. The command also generates a white-background contact sheet for small-size inspection.

Light-background assets use ink `#0a0a0a` and dark emerald `#065f46`. Dark-background assets use
white `#ffffff` and emerald `#10b981`. Strict monochrome assets remain black or white. The mark
contains no blue.

## Usage

- Keep horizontal clear space at least 50% of mark height and icon clear space at least 25%.
- Use the full wordmark no smaller than 120 px digital width or 35 mm print width.
- Use the standard icon no smaller than 24 px or 10 mm. Use the optically adjusted 16 px asset for
  favicons.
- Keep the upper `V` and lower mirrored check attached at their center.
- Do not symmetrize the lower check, substitute a font `X`, stretch, rotate, outline, shadow,
  gradient, glow, or recolor the components outside the approved ink/emerald pairs.
- Do not infer formal proof from the check shape. Xerify provides a bounded cross-provider second
  opinion.

## Distribution

Canonical production vectors and generated icon exports are repository assets, not npm runtime
files. Local review sheets and design workspaces are ignored development material. The package
allowlist and `.npmignore` exclude every brand asset from published tarballs.

## Approval status

The attached-center asymmetric geometry, custom wordmark, and ink/emerald direction were approved by
the owner on 2026-08-19. Deterministic asset checks remain a release gate for every future change.

## Product narrative

Born as Deckent’s native verification command and layer, Xerify also runs as a standalone
CLI, library, and MCP server. Its value is bounded evidence, invocation-provider separation,
consistent verdicts, and inspectable run history across supported verification backends.
Jev adds typed probabilistic decisions alongside LLM verifiers.

Use “LLM verifiers and typed decision models” when describing 0.3.0. Do not promise automatic
escalation, ensembles, deterministic proof, independently calibrated accuracy, or speed/cost
improvements without implementation and measurements. Jev confidence describes a probability
distribution; it is not the probability that a decision is true. Its adapter supplies no
generated rationale or evidence citations. The three verdicts and provider separation remain.

## Motion assets

`npm run assets:flow` renders the existing paper-and-ink visual system with the approved wordmark.
The 16-second loop shows two separate runs: an LLM review and a Jev typed decision. It never
represents automatic fallback or two providers called in one run. Jev's illustrative probability
and confidence are below the default policy, so the displayed result is `unclear`. Values are
illustrations, not live measurements or accuracy claims.

Use `assets/readme/xerify-verification-flow.gif` for README animation,
`xerify-verification-flow-poster.png` for the static Jev view, and
`xerify-verification-flow-social.png` for a 1920 × 1080 still. The renderer requires ffmpeg and
uses the existing paper texture; it does not alter the logo geometry.
